# Changelog

## S2IsoMEr 1.0.0

- Added a new vignette `METASPACE to S2IsoMEr` to convert METASPACE
  datasets to a compatible format for S2IsoMEr.
- Migrated all internal and external data to
  [S2IsoMErData](https://github.com/alexandrovteam/S2IsoMErData)

## S2IsoMEr 0.5.0

- Added a wrapped function `metap_sumlog_pvals` for combining p-values
  using Fisher’s method.
- Removed unnecessary dependencies
- Moved fgsea and BioCparallel to suggests
