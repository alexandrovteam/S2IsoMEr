# S2IsoMEr: Spatial and Single-Cell Isomeric Metabolite Enrichment in R

R package performing Overrepresentation analysis (ORA) and Metabolite
Set Enrichment Analysis (MSEA) on Spatial and single-cell metabolomics
datasets using bootstrapping of isomeric/isobaric molecules.
